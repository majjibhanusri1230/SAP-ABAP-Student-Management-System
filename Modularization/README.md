# Modularization Directory

This directory contains modularization implementations:

- `zbha_student_modular.abap`: Subroutines (`FORM` / `PERFORM`) for data retrieval and reporting.
- `zbha_student_params.abap`: Subroutine parameter passing demonstration (`USING` and `CHANGING`).
- `zbha_student_reusable_validate.abap`: Reusable validation subroutine for marks boundary verification (`0` to `100`).
